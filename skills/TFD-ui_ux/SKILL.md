# ui_ux

Specify reusable component behavior, state ownership, keyboard/focus and measurable accessibility acceptance. Justify exceptions to the project design system with user-flow evidence; route uncertain platform behavior to bounded research.

For material technical gaps, use the [decision procedure](../../library/architecture/technical-decision-procedure.md); reuse project evidence and load only applicable sources.

Document users, journeys, components, tokens, responsive states and accessibility acceptance. Reuse relevant project patterns and record source revisions. Specify loading, empty, error, denied and success behavior. Maintain a project-local visual guide in the product stack when requested. At review, compare the running revision against approved states and report observable differences; implementation stays with frontend.
